# NFA-007: Join the first full stack path and publish guides

## Status

Planned

## User story

As a user, I want one full path so I can try the planned product shape.

## Goal

Join the web and API. Publish proof and clear start guides.

## Dependencies

`NFA-001` through `NFA-006`.

## Acceptance criteria

- [ ] The Angular plan screen calls the typed preview API and shows input, loading, success, and failure states.
- [ ] The UI shows the active local provider and model without exposing internal URLs or secrets.
- [ ] A supplied Penpot link is inspected before planning when MCP is available, and the approved design keeps real handoff IDs.
- [ ] Playwright captures reviewed desktop and narrow-screen evidence with invented data and a screenshot index.
- [ ] README and user guide show the verified path, current screenshots, and exact commands for both Ollama modes.
- [ ] Architecture and setup flowcharts use a top-to-bottom Mermaid layout by default.
- [ ] Release verification records both real-model modes, focused checks, design proof, review, and the approved commit.
- [ ] No planned Release 0.2 feature is described as current behavior.

## Out of scope

This story does not add durable tasks, file upload, multi-file work, or observability services.
