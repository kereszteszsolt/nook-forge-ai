# Applications

The repository has two application roots:

- `apps/api` for the Java 21 and Spring Boot modular monolith;
- `apps/web` for the Angular and TypeScript user interface.

The verified Spring Boot API, PostgreSQL foundation, and container image are included under `apps/api`; the verified Angular shell and static Nginx image are included under `apps/web`. The joined runnable product flow remains planned through `NFA-007`.
